Wayfarer 한국어 보조 애드온 v2 (0.2.0)

[설치]
게임을 종료하고 Wayfarer_KoreanUI 폴더를 Interface\AddOns에 넣으세요.
이미 v1이 있다면 그 폴더만 v2로 교체하세요. NN/NNAV 폴더는 바꾸지 않습니다.
애드온 목록에서 'Wayfarer 한국어 UI'를 켜세요. 필요하면 구버전 애드온 불러오기를 체크하세요.

[현재 사용할 수 있는 것]
/wfko 켜기 : Wayfarer 패널의 확인된 문구를 한국어로 표시
/wfko 끄기 : 원래 표시로 복구
/wfko 찾기 : 패널 다시 찾기
/wfko 학습 켜기 : RXPGuides의 기존 상급자 자동 학습 설정 켜기
/wfko 학습 끄기 : 상급자 자동 학습 끄기
/wfko 장비안내 켜기 : RXPGuides 장비 비교/도움말 설정 켜기. /reload 후 확인
/wfko 장비안내 끄기 : 장비 비교 안내 끄기. 일반 도움말 설정은 그대로 유지

학습은 상급자 창을 열었을 때 RXPGuides가 가진 직업/종족/레벨/가이드 목록을 따릅니다.
새로운 AI 학습 계획이나 상급자 자동 방문을 구현한 것은 아닙니다.
장비 안내는 비교 기능이며, 자동 착용은 아직 연결되지 않았습니다.
기능을 켜는 명령을 직접 입력하기 전에는 RXPGuides 설정을 바꾸지 않습니다.

[길찾기·끼임·자동착용 개선을 위한 진단]
1. Wayfarer 패널을 연 뒤 일시정지하세요.
2. 채팅에 /wfko 진단 을 입력하세요.
3. 진단 준비 완료 메시지를 확인하고 /reload 하거나 게임을 정상 종료하세요.
4. 게임 폴더의 WTF 아래에서 Wayfarer_KoreanUI.lua 파일을 찾아 채팅에 첨부하세요.
   일반적인 위치: WTF\Account\...\SavedVariables\Wayfarer_KoreanUI.lua
   .lua.bak 파일이나 계정/라이선스 파일은 보내지 마세요.

보고서는 일반 애드온이 볼 수 있는 모듈·함수 이름과 일부 상태, 직업 코드/레벨/클라이언트 버전만 수집합니다.
계정 비밀번호, 라이선스, 설정 문자열 값, 원본 파일 내용, 함수 본문은 수집하지 않습니다.
이동·학습·구매·장비착용 함수를 호출하지 않으며 외부로 전송하지 않습니다.
NN의 별도 실행 공간에만 있는 기능은 보고서에 나타나지 않을 수도 있습니다.

[확인 범위]
Lua 5.1에서 원문/버튼 동작 유지, 표시 켜기/끄기, 진단의 동작 함수 미호출,
비밀 값 제외, RXP 설정 명령의 동작을 모의 환경에서 검사했습니다.
실제 와우에서 실행 검증은 하지 못했습니다.

원래 Wayfarer와 NNAV, 로그인, 전체화면 설정은 수정하지 않았습니다.
되돌리려면 애드온을 끄거나 Wayfarer_KoreanUI 폴더를 삭제하세요.
명령으로 직접 켠 RXPGuides 학습/장비 비교 설정은 해당 끄기 명령이나 RXP 설정에서 꺼야 합니다.
