Wayfarer 한글 표시 보조 — 16001 호환 수정판 v3 (0.2.1)

대상: 사용자 확인 버전 1.6.0.1 / 빌드 10862 / TOC 16001
이전 파일은 11509로만 지정되어 대상 클라이언트를 반영하지 못했습니다.
이번 파일의 Interface 값은 16001입니다.

1. 게임을 완전히 종료하세요.
2. 기존 Interface\AddOns\Wayfarer_KoreanUI 폴더를 백업하고 새 폴더로 교체하세요.
3. 아래 위치에 toc 파일이 있어야 합니다.
   Interface\AddOns\Wayfarer_KoreanUI\Wayfarer_KoreanUI.toc
   압축파일 이름의 상위 폴더를 한 겹 더 넣지 마세요.
4. 게임을 다시 실행해 애드온 목록의 'Wayfarer 한글 표시 보조'를 켜세요.
5. 캐릭터 접속 후 다음과 비슷한 메시지를 확인하세요.
   보조 애드온 0.2.1 로드됨 · TOC 16001
6. Wayfarer 패널을 연 뒤 /wfko 켜기, /wfko 를 각각 입력하세요.
   '찾은 창 N개 · 번역 문구 N개'가 나옵니다.

로드 메시지가 없으면 아직 애드온 로딩이 확인되지 않은 것입니다.
로드됐지만 찾은 창/문구가 0개면 현재 Wayfarer 화면 구조가 감지되지 않은 것입니다.
결과 메시지를 알려주면 이 두 경우를 구분해 이어서 확인할 수 있습니다.
화면에 오류 문구가 나오면 /wfko 에서 마지막 오류도 확인할 수 있습니다.

이 패키지는 확인된 Wayfarer 표시 문구에 한국어를 덧씌우는 별도 애드온입니다.
Wayfarer 본체의 완역판이 아니며, 미확인 문구와 별도 창에는 영어가 남을 수 있습니다.
제작 환경에서 실제 와우 화면을 실행해 검증하지는 못했습니다.

/wfko 끄기 로 원래 표시로 복구할 수 있습니다.
표시 중 오류가 발생하면 보조 기능을 멈추고 원래 글자를 복구하도록 했습니다.
NN/NNAV, relogger, 라이선스, 원본 Wayfarer 코드, 전체화면 설정은 변경하지 않습니다.

v2에 포함했던 기존 RXP 설정 명령과 읽기 전용 진단 명령도 유지됩니다.
/wfko 학습 켜기 또는 /wfko 학습 끄기
/wfko 장비안내 켜기 또는 /wfko 장비안내 끄기
/wfko 진단
위 설정 명령을 입력할 때만 RXPGuides의 기존 설정을 변경합니다.
장비안내는 자동 착용이 아닙니다. 길찾기/끼임/자동착용 연결은 아직 미완료입니다.
