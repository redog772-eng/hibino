Wayfarer 한국어 UI 보조 애드온 0.1

1. 게임을 종료하세요.
2. Wayfarer_KoreanUI 폴더를 게임의 Interface\AddOns에 넣으세요.
3. 캐릭터 선택 화면의 애드온 목록에서 'Wayfarer 한국어 UI'를 켜세요.
   필요하면 '구버전 애드온 불러오기'를 체크하세요.
4. 게임에서 Wayfarer 패널을 열면 확인된 버튼·상태 문구를 한국어로 표시합니다.

/wfko        상태와 사용법
/wfko 끄기   한국어 표시를 끄고 원래 표시로 복구
/wfko 켜기   한국어 표시 켜기
/wfko 찾기   패널을 다시 찾기

범위: 제공된 화면의 메인 패널 문구 및 자주 쓰는 설정/상태 문구.
원래 문구와 버튼 동작은 바꾸지 않고 한국어 글자를 위에 표시합니다.
확인되지 않은 문장이나 별도 팝업·다른 애드온에는 영어가 남을 수 있습니다.
실제 게임 화면에서는 아직 확인하지 못했습니다.

이 파일은 UI 한글화만 합니다. 길찾기/기술/장비 행동 개선은 아직 연결하지 않았습니다.
NNAV, 로그인, 화면 모드, 계정/라이선스 설정은 변경하지 않습니다.
되돌리려면 애드온 목록에서 끄거나 Wayfarer_KoreanUI 폴더만 삭제하세요.
