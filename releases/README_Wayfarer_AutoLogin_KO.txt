Wayfarer / NN Relogger V9 - 연결 중 화면 자동 복구 + 계정 로그인

[무엇을 하는가]
정상적으로 수동 로그인되는 아이디/비밀번호를 이 PC에서 한 번 설정합니다.
게임 시작 후 정확히 '연결 중' 팝업이 지정 시간 이상 유지되면,
일반 취소 버튼과 같은 C_Login.DisconnectFromServer API를 한 번 호출합니다.
다음 로그인 갱신에서 캐시된 재접속 대신 입력한 계정으로 로그인을 시도합니다.
캐릭터 선택 화면 이후에는 자동 조작하지 않습니다.
본래 첫 연결 시도가 멈추는 내부 원인까지 해결했다는 의미는 아닙니다.

[적용]
1. 게임과 NN 메인 로더를 종료합니다. NNAV/9910 설정은 그대로 둡니다.
2. 이 ZIP을 새 폴더에 압축 해제합니다.
3. SETUP_AUTOLOGIN.cmd를 실행합니다. Python 3 / tkinter가 필요합니다.
4. load_glue 폴더가 들어 있는 실제 NN 설치 폴더를 선택합니다.
   예: C:\Users\User\Desktop\NoName_Release
5. 게임에서 수동 접속에 성공하는 아이디와 비밀번호를 입력합니다.
   WoW 계정 선택명은 여러 게임 계정 선택 창이 나오는 경우에만 해당합니다.
6. 자동 로그인 설정을 누릅니다. NN과 WoW를 다시 시작합니다.

[복원과 변경 범위]
변경 파일은 load_glue/reloggerV9.lua와 load_glue/account_data.json뿐입니다.
설정 전 원본 두 파일은 NN 폴더의 relogger-autologin-backups 아래에 보관됩니다.
문제가 생기면 게임과 NN 종료 후 같은 도우미의 '마지막 설정 원복'을 사용합니다.
기존에 쓰던 것과 다른 버전의 Lua 파일이면 자동 수정을 중단합니다.
NN/NNAV EXE, 라이선스, 방화벽, URL 예약, 맵, 게임 설정은 변경하지 않습니다.

[개인정보]
NN 기본 동작에 맞춰 비밀번호가 로컬 account_data.json에 평문으로 저장됩니다.
원본 백업에도 기존 계정 정보가 있을 수 있습니다. 계정 파일과 백업은 공유하지 마세요.
이 설정 도우미에는 외부 전송/로그인 서버 접속 기능이 없습니다.
이 ZIP에는 사용자 계정 정보, 라이선스 또는 NN 실행파일이 들어 있지 않습니다.

[검증 범위]
사용자가 제공한 EPICRENAMEME.zip의 relogger V9를 기준으로 제작했습니다.
Lua 5.4 모의 UI에서 기존 연결 창 대기를 재현하고, 한 번 취소/계정 로그인,
꺼진 설정, 비활성 옵션, 인증번호/CAPTCHA/오류/대기열, 숨은 로그인 화면,
누락된 API, 구형 텍스트 접근, 한국어 텍스트, 정상 직접 로그인 조건을 검사했습니다.
실제 WoW Forever 클라이언트의 수정 UI/NN 로더와 Windows GUI 동작은 미검증입니다.
설정 적용/배열 한 계정/백업/복원/알 수 없는 버전 거부/쓰기 실패 복구 등
Python 로직 검사를 통과했습니다. 다른 버전 스크립트는 임의로 덮어쓰지 않습니다.
